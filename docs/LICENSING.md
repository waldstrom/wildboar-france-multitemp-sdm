## Repository licence

The source code, configurations and original documentation are released under **BSD-3-Clause**, using the [standard BSD 3-Clause terms](https://opensource.org/license/bsd-3-clause). This completes the licence already named in the repository README. It permits reuse and modification, including commercial use, with notice-retention and non-endorsement conditions. The full [LICENSE](../LICENSE) is authoritative.

## Material-specific scope

| Material | Applicable terms |
|---|---|
| Original code, configs and repository documentation | BSD-3-Clause |
| Python and native-library dependencies | Their respective licences; installing them does not relicense them |
| GBIF occurrence downloads | Per-download/provider terms and attribution; preserve the GBIF download DOI |
| RRN and SNCF collision records | Data-owner permissions and project agreements |
| Environmental and administrative products | Provider-specific licences, attribution and access conditions |
| Third-party pretrained model weights and imagery | Their own model/data licences |
| Manuscript, preprint and supplement | Publication-specific terms, separate from this software licence |
| New derived outputs | Assess source-data terms and applicable authorship; not automatically covered by the software licence |

Input data, fitted models and publication PDFs are not bundled. Follow the [data guides](../data/README.md) for access routes and keep original source attribution.

## Citation metadata

[CITATION.cff](../CITATION.cff) follows [Citation File Format 1.2.0](https://github.com/citation-file-format/citation-file-format/blob/main/schema-guide.md). It distinguishes software authorship from the preferred five-author study citation. [codemeta.json](../codemeta.json) supplies software discovery metadata.

The Research Square DOI identifies preprint Version 1. No software DOI, release version, ORCID or final journal citation is invented. When an archived software release or final article exists, update the relevant metadata using verified identifiers while preserving the provenance of past runs. Citation is a scientific attribution request; it does not add a fourth condition to the BSD licence.
